# Проверка ролями

Роли (аналитик, разработчик, тестировщик и другие) подтверждают требования. Это дорого: по прошлым замерам 15–25 тысяч токенов на документ.

## Правила

- По умолчанию проверка **выключена**: `role_review.enabled: false` в `docs/gates.yaml`.
- Включает только человек и только с лимитом `max_tokens`. Включение без лимита блокируется `check.py`.
- Перед запуском называется оценка расхода.
- Запускать нужно выборочно: для рискованных компонентов, а не для всего проекта.

## Какая отметка считается подтверждением

Отметка действительна для текста, который проверялся. Изменился текст требования, значит отметка устарела.

Отметки, перенесённые из другого проекта, это история: `origin: imported`. Они не считаются подтверждением и не показываются зелёными, пока роль не проверит новую версию.

Отметку ставит роль или человек, скрипт и автор документа её не ставят.
