# doc-rules

Правила проверки качества документации, исследования и план работ. Совместимо с BMad Method, официальным продуктом не является.

Начните с [описания сценария и репозиториев](docs/new-project.md).

## Главное

- **Два слоя.** Слой для ИИ хранит факты, слой для человека генерируется из него.
- **Сначала скрипт, затем LLM, затем человек.** Скрипты без единого токена нашли в примере 8 блокеров.
- **LLM-гейты запускаются только в минимальном контексте.** Обычный агент тратит около 33 тысяч токенов ещё до работы, минимальный запуск 866.
- **LLM ищет дефекты, но не доказывает полноту.** Известный блокер находится не в каждом запуске, на воротах решает человек.
