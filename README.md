# BMAD-rules

Правила проверки качества документации BMAD и план их автоматизации. Пример документации, на котором они опробованы, находится в репозитории `documentation_docmost`.

## Главное

- **Сначала скрипт, затем LLM, затем человек.** 8 из 12 новых гейтов могут работать почти или совсем без токенов.
- **LLM-гейты запускаются только в минимальном контексте.** Обычный агент тратит около 33 тысяч токенов ещё до работы, минимальный запуск 866.
- **LLM ищет дефекты, но не доказывает полноту.** Разные запуски находят разное, на воротах решает человек.

## Запуск гейта

```
python tools/build_packet.py G01 --out packets/G01.md
python tools/run_gate.py G01 --packet packets/G01.md --out results
```

`run_gate.py` использует Claude Code. Если `claude` нет в `PATH`, укажите путь в переменной `CLAUDE_BIN`.

## Ограничения

Замеры сделаны на одном вымышленном примере, по одному запуску на модель и гейт. Точность и полнота гейтов не измерены, это задача T-02. Токены проверок BMAD пока оценены по размеру документов и ещё не замерены, это задача T-19.
