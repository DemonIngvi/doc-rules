# План: вспомогательные инструменты для человека

Статус: работает первая версия: движок `doc-guide`, сервер MCP, пять наборов шагов и панель Docmost в LibreChat. Диалог с моделью не проверен: модель подключается отдельно. Исследование: `research/helpers-librechat.md`.

Решение владельца: инструменты делаются **отдельными подпроектами**, не внутри существующих репозиториев, и каждый отдельно.

## Цель

Помогать человеку проходить процесс: задавать правильные вопросы, заполнять правильные шаблоны, не пропускать шаги.

## Подпроекты

| Подпроект | Для каких работ | Что делает |
| --- | --- | --- |
| `rnd-helper` | R&D и исследования | Ведёт по этапам, задаёт вопросы, заполняет шаблоны исследования |
| `sdd-helper` | ТЗ, use case, требования, спецификации | Ведёт по сценариям, задаёт вопросы, заполняет шаблоны требований |

## Что учесть на старте

- Сначала сделать R&D, что существует и какой формат удобен: диалог, форма, навык агента.
- Опора для `rnd-helper`: `rules/rnd.md` и `skills/doc-rnd.md` в `methodology`, `bmad-deep-recon`.
- Опора для `sdd-helper`: `rules/sdd.md`, `rules/user-stories.md`, `rules/spec-criteria.md`, классы S1–S12, `bmad-prd`, `bmad-spec`.
- Шаблоны и правила брать из общих источников, а не копировать, чтобы они не расходились.
- Каждый подпроект независим и подключается к проекту через файл версий `doc-kit`.
